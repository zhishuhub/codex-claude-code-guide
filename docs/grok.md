# Grok 一键配置教程（Windows / Mac）

把 grok-app 桌面版接到智枢，用 Grok 模型聊天、写代码。不用手填密钥，配好就能用。

[← 返回目录](../README.md)

## 1. 登录并选择 Grok

[打开智枢并登录](https://zhishuhub.com/sign-up?aff=zbD0)，确认账户余额充足。

[打开安装配置向导](https://zhishuhub.com/guide?aff=zbD0)，选择「Grok」（grok-app）和你的电脑系统。

## 2. 安装 grok-app（已有可跳过）

在向导里点「还没有，去下载」，下载安装包。装好后打开一次，等初始化完成，再完全退出。

## 3. 一键配置

在向导里点「已经装好，下一步」。

### Windows

1. 点「下载配置工具」，浏览器询问时选「保留」。
2. 双击下载的文件，等窗口提示配置完成。
3. 打开 grok-app，开始对话。

### Mac

1. 点「生成命令」，再点「复制命令」。
2. 打开「终端」，粘贴完整命令并回车。
3. 等配置完成，打开 grok-app，开始对话。

配置工具只替换「智枢」这一个提供方，grok-app 里你自己加的其他提供方都保留。

## 4. 发消息验证

发一句「你好，请用中文回复」，收到正常回复就配好了。

## 常见问题

### Windows 提示「Windows 已保护你的电脑」

点「更多信息」，再点「仍要运行」。

### 提示配置码过期或已使用

配置码 30 分钟内有效，只能用一次。回网站重新生成即可。

### 配置后没有回复

先看账户余额，再完全退出 grok-app、重新打开。还不行就到 [QQ 群](https://qm.qq.com/q/UXdEAUEFCC)（群号 1106399716）求助，不要公开密钥或完整配置命令。
